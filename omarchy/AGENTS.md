- For elevated commands, use `pkexec --disable-internal-agent <cmd>` (not `sudo`) so the desktop Polkit dialog pops up. Group multi-step admin commands into a single `pkexec --disable-internal-agent sh -c '...'` call; if canceled or timed out, stop and ask before retrying.
- For secrets, use the `1password` MCP server or desktop-integrated `op run` / `op read` (never `op signin`).
